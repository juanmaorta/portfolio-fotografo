# Portfolio de Martín Soler — Fotografía

Web de portfolio de un fotógrafo ficticio, creada como material de clase para
el curso de FrontEnd de Shifta. La usamos para practicar **programación
asistida con IA**: pedir cambios, entender el código generado y verificar
el resultado.

## Qué contiene

| Archivo | Qué es |
|---|---|
| `index.html` | Landing con la hero |
| `biografia.html` | Página de biografía |
| `portfolio.html` | Galería de obras |
| `styles.css` | Estilos compartidos (paleta en variables CSS) |
| `datos.js` | Datos de las obras de la galería |
| `script.js` | Lógica: pinta la galería y el año del footer |

## Cómo verla

No necesitas instalar nada: descarga el proyecto y abre `index.html`
con doble clic en tu navegador.

Las imágenes vienen de [picsum.photos](https://picsum.photos), así que
necesitas conexión a internet para verlas.

## Tecnología

HTML, CSS y JavaScript a secas. Sin frameworks, sin dependencias,
sin proceso de build.
